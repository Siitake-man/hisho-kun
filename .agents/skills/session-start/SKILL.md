# スキル：セッション開始準備 (session-start)

このスキルは、プロジェクト「ネオ秘書くん（Neo-Secretary）」における新しい開発セッションを開始する際に、AIが自律的に実行する一連の準備・同期手順です。前回の文脈を迅速に復元し、スムーズに作業に入ることを目的とします。

## 実行フロー

AIは本スキルを検知またはユーザーから指示された場合、以下のステップを**すべて自律的に一括で実行**します。

### ステップ0：codebase-memory-mcp ＆ MentisDB 記憶同期・想起
1. **codebase-memory-mcp インデックス最新化**:
   - `index_repository` または `detect_changes` を呼び出し、最新コードの知識グラフを自律更新する。
2. **MentisDB (ADR / 設計知見) の想起**:
   - `manage_adr` ツール（`mode='get'`）を実行し、前回のセッションで永続化された「設計決定・アーキテクチャ・直前ステータス・Gotcha」をナレッジグラフから瞬時にクエリして想起する。これにより、記憶の連続性を完全に担保する。

### ステップ1：最新コンテキストの自動スキャンと同期
AIはプロジェクト内の以下のファイルを順番に読み込み、現在のプロジェクト状況を完全に復元します。
1. **`docs/00_ドキュメント一覧.md`**: 全ドキュメントの所在と最終更新日の確認
2. **`active_context.md` / `機能ロードマップ.md`**: 直近のタスク進捗状況と完了状態の把握
3. **最新の `学習メモ_YYYYMMDD.md`**: 前回の詳細な振り返りと直近の課題

### ステップ2：Jules / Codex の成果確認と同期（非同期リレーの受け取り）
AIは、他エージェントが裏で進めていた作業を確認します。
1. **コミット・差分の確認**: コミットログから変更内容を確認する。
2. **引き継ぎメモ・学習メモの読み込み**:
   - `jules_handover.md` や `codex_handover.md` が存在すれば確認する。

### ステップ3：環境の健全性チェック
1. **カレントディレクトリの確認**: `ネオ秘書くん` フォルダ直下にいることを確認。
2. **環境変数の整合性チェック**: `.env` の存在と主要キー（`GOOGLE_API_KEY`, `OPENCODE_API_KEY` 等）の確認。

### ステップ4：5分マイクロタスクの特定
今日の最初の「小さな勝利（Small Win）」を定義します。
- 前回の `学習メモ` の「次回再開時の最初のタスク」とロードマップから、最も早く（5分以内）完了できる作業を1つ特定します。

### ステップ5：ユーザーへのセッション再開宣言
すべての準備が完了した後、AIはユーザーに以下のフォーマットで報告し、合意を得て最初のタスクに着手します。

```markdown
### 🌅 セッション再開準備完了

前回の文脈および Jules / Codex の作業成果を同期・復元しました。

**【現在の状況】**
- **現在のフェーズ**: ○○ 
- **他エージェントによる変更**: ○○ 
- **直近の決定事項**: ○○ 

**【今日の最初のアクション】**
- [ ] ○○ (例: 実機での動作確認など)

それらの確認から作業を開始してよろしいでしょうか？
```

## 留意事項
- アプリ起動コマンド（`python main.py`等）は自動実行せず、ユーザーに対して起動コマンドを提案・確認すること。
