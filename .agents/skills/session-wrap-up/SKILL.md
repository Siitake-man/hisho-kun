# スキル：セッション終了振り返り (session-wrap-up)

このスキルは、プロジェクト「ネオ秘書くん（Neo-Secretary）」における開発セッション終了時に、AIが自律的に実行する一連の振り返り・同期手順です。ユーザーの可処分時間を最大化し、「再開時にゼロから思い出す時間」を完全に排除することを目的とします。

## 実行フロー

AIは本スキルを検知またはユーザーから指示された場合、追加の対話による時間浪費を避けるため、以下のステップを**すべて自律的に一括で実行**します。

### ステップ1：セッションファクトの構築（脳内整理）
AIはまず、本セッションで実行した以下の情報を整理します。
- `CompletedTasks`: 完了したタスクの一覧
- `Troubles`: 遭遇したエラー、原因、対策の3点セット
- `ModifiedFiles`: 作成・修正したファイルとそれぞれのシステム上の役割
- `SpecsModified`: 変更した仕様や影響のある仕様書
- `NextAgentTasks`: JulesやCodex（夜間/非同期エージェント）に委ねるべきタスク
- `NextAction`: 次回再開時に迷わず5分で着手できる超具体的なファーストアクション

### ステップ2：既存ドキュメントの自動更新
AIはまず `docs/00_ドキュメント一覧.md` を読み込み、以下の更新を自律的に実行します。冒頭ヘッダーの「最終更新」日時（YYYY-MM-DD HH:MM形式）を必ず更新します。

1. **タスク進捗管理ファイルの更新**: `機能ロードマップ.md` および `active_context.md` の完了タスクを更新。
2. **`docs/00_ドキュメント一覧.md` の更新**: 変更したドキュメントの「最終更新」欄を全件更新する。

### ステップ3：学習メモの自動生成（Obsidian Vault同期 ＆ ローカル保存）
AIは以下の2つのパスに、詳細なストーリー＆メタ認知型学習メモを作成します。

1. **Obsidian Vault（Google Drive同期フォルダ）への書き出し ⭐ (推奨フォーマット)**:
   - **保存先**: `G:\マイドライブ\Obsidian_Antigravity\Projects\ネオ秘書くん\YYYY-MM-DD_ネオ秘書くん.md`
   - **上書き禁止ルール**: 同日ファイルが既に存在する場合は絶対に上書きせず、末尾に追記（Append）すること。
   - **フォーマット**: ハイブリッド Zettelkasten ＆ ストーリー型。`#ドラマ` `#感情` `#判断理由` `#第一原理` タグと、重要キーワードの双方向リンク `[[ ]]` を含めて出力する。

2. **プロジェクトローカルへの保存**:
   - **保存先**: `学習メモ_YYYYMMDD.md`
   - **上書き禁止ルール（絶対遵守）**: 既存ファイルが存在する場合は末尾に追記（Append）すること。

### ステップ4：Jules / Codex への引き継ぎ指示書の自動生成
AIは以下のパスに、夜間/非同期エージェント向けの指示書を作成します。
- **保存先**: `prompt_for_jules.md` または `prompt_for_codex.md`
- **内容要件**: エージェントが迷わないよう、対象ファイルパス、コーディング規約、デザインシステムへの参照を含め、日本語で詳細に指示を記述する。

### ステップ5：codebase-memory-mcp ＆ MentisDB 記憶永続化
1. **codebase-memory-mcp インデックス最新化**:
   - `index_repository` を呼び出し、本日変更された全コード構造・関数・依存関係をグラフDBに自律反映・最新化する。
2. **MentisDB (ADR / 設計知見) の永続化**:
   - `manage_adr` ツール（`mode='update'`）を実行し、本日の設計決定・アーキテクチャ変更・Gotcha（詰まりどころと解決策）・次期ステータスをグラフDBに永続化する。これにより、次回セッション開始時にエージェントが瞬時に直前の状態と判断理由を想起可能にする。

### ステップ6：ユーザーへの最終出力（5大打返し）
1. **【今日やったこと＆詰まったポイント】** サマリーと、事象・原因・対策の3点セット。
2. **【🧠 記憶永続化レポート】**
   - **Codebase インデックス最新化**: `index_repository` の実行結果（プロジェクト名、ノード数、エッジ数）。
   - **MentisDB / ADR 永続化**: `manage_adr` で保存したADR番号、タイトル、主要な決定事項。
3. **【Git一括コマンド】** ユーザーがコピー＆ペーストするだけでコミットとプッシュが完了する一括コマンド（PowerShell互換）。
4. **【Jules / Codex Web UI用指示プロンプト】** ユーザーがコピペして送信できる短いテキスト。
5. **【次回再開時の魔法のプロンプト】** 文脈と他エージェントの成果を同期するための引き継ぎプロンプト。

## 留意事項
- コマンド実行の制限ルールに基づき、`git` コマンド等の自動実行は行わず、ユーザーに提示して実行を促すこと。
