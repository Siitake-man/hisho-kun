# ネオ秘書くん v1.1.0 — Agent Bridge & Zero-Trust Architecture Update 🚀

「**席を外しても、AIコーディングエージェントが止まらない。**」  
眠っていた古いスマートフォンを卓上Desk Pet＆遠隔承認リモコンへと転生させるOSS『ネオ秘書くん』が、初の大型マイナーアップデート **v1.1.0** を迎えました！

本バージョンでは、ローカル社内LAN環境における「ゼロトラスト端末認証」の確立、AI安全審査スコアを可視化する「インテリジェント承認カード」、そしてクロスプラットフォームCI/CDによる完全自動テスト環境を配備しました。

---

## 🌟 主な新機能・ハイライト

### 1. 🛡️ ゼロトラスト端末認証 ＆ ペアリング保護
- **暗号論的個別トークン (`storage/device_repo.py`)**:
  各スマホ端末ごとに独立した256bit暗号トークンを発行。トークンハッシュによる検証で、社内LAN内でも他端末への成りすましを完全防御。
- **未承認端末接続時の Human-in-the-Loop 承認**:
  新しいスマホが接続を試みた際、PC画面上にカウントダウン付きの承認ダイアログがポップアップし、ボスの許可なしには接続を一切受け付けない Fail-Closed 遮断を実現。

### 2. 🟢 インテリジェント遠隔承認カード ＆ Jev安全審査バッジ
- **AI審査スコアのリアルタイム点灯 (`web_pet/pet_ui.js`)**:
  Claude Code, Cline, Antigravity などの外部エージェントが実行したコマンド安全審査（Jev等のTool Guard）の結果を受信し、スマホDesk Pet画面上でエメラルドグリーンのネオンバッジ（`🟢 Jev安全審査: ALLOW`）を自動点灯！
- **多重防御（Defense-in-Depth）データパイプライン**:
  概要（summary）や見出し（title）から安全スコアを自動抽出し、破壊的変更（`rm -rf`, `git reset --hard` 等）のリスクを視覚的に即座に判別可能。

### 3. 🔋 Desk Pet PWA 適応型 Canvas 0fps 省電力化
- **バッテリー負荷の劇的低減**:
  スマホを常時机上に置いても熱を持たないよう、ペット静止時は Canvas 描画ループを 0fps に完全スリープ。通知やタップ等のイベント時のみ瞬時に復帰する「Wake-on-Demand」設計。
- **PWA v1.1.0 キャッシュ自動パージ**:
  アセット更新時の古いJavaScriptキャッシュ滞留を自動パージするキャッシュバスター機構を確立。

### 4. 🚀 クロスプラットフォーム CI/CD 完全対応
- **GitHub Actions 自動テストパイプライン (`.github/workflows/ci.yml`)**:
  Ubuntu (ヘッドレスXvfb) ＆ Windows 64bit × Python 3.11, 3.12, 3.13 の全環境マトリクスで、全660+テストを完全走破（ALL GREEN）。
- **リリース品質の恒久担保**:
  静的構文チェック（Fail-Fast Lint）および機密情報漏洩スキャン（Secret History Scan）を毎プッシュ自動実行。

## 🛠️ 改善・バグ修正
- **終礼日報の集計ロジック修正**: `get_tasks_completed_today()` の Seam 分割により、過去の完了タスクが当日の日報に重複混入する不具合を根治。
- **ループバック台帳のクリーンアップ**: デスクトップローカル通信（`127.0.0.1`）が端末台帳に登録されてしまうノイズを排除。
- **バージョン定数の一元化**: `version.py` を Single Source of Truth とし、`version.js` 動的配信と全アセットの整合性を完全同期。

## 📦 ダウンロード ＆ アップデート方法

### 新規インストール
1. 添付の `NeoHisho_v1.1.0_win64.zip` をダウンロードし、任意のフォルダに解凍します。
2. フォルダ内の `NeoHisho.exe` をダブルクリックして起動します。

### 既存ユーザーのアップデート
1. `NeoHisho.exe` を終了します。
2. 本zipを展開した中身で上書きコピーしてください（※設定やTODOデータ `neo_secretary.db` は `%APPDATA%` 内に安全に保持されるため消えません）。
