# NeoHisho v1.0.0 — 初回配布リリース 🎉

**ネオ秘書くん (Neo-Secretary)** の初回配布バージョンです。

## 📥 ダウンロード
下記 **Assets** の `NeoHisho_v1.0.0_win64.zip` (60.6 MB) をダウンロードしてください。
**Git の操作は不要です。** ブラウザだけで完結します。

## ✨ このバージョンの主な機能
- 🐾 **デスクトップペット秘書くん** — タスク管理を優しく伴走（担当キャラ: 秘書くん ＆ カイル）
- ✅ **TODO / カレンダー / 習慣トラッキング**（TickTick風UI・4象限ビュー・70日ヒートマップ）
- ⏰ **時刻ベースリマインダー** — 期限10分前にPC吹き出し＋スマホへ通知
- 🧭 **AI生活コーチ** — 2時間ごとに生活データ（タスク完了率・習慣・期限切れ）を分析しマイクロ提案を生成（ローカルLLM/クラウドLLM選択式・統計データのみ送信・障害時はルールフォールバック）
- 🌤️ **ペットの自律生活** — 食事・仕事・睡眠などをAIが生成、リアル天気も反映
- 📱 **スマホPWA連携** — LAN/Tailscale経由でTODO操作・通知・ペット表示・ペアリング
- 📰 **AIニュースサマリ** — Google News RSS を3行に要約（キーワードカスタマイズ可）
- 🌐 **多言語基盤** (ja/en) ＋ 🎮 シークレットミニゲーム ＋ イースターエッグ演出

## 🚀 セットアップ（初回）
1. zip を展開（`NeoHisho.exe` と `_internal` が並ぶ状態）
2. `NeoHisho.exe` をダブルクリックで起動
3. AI機能のプロバイダ選択:
   - **ローカルLLM（無料・オフライン）**: PowerShell で `.\NeoHisho.exe --setup-model 350m`（約230MBを自動ダウンロード）
   - **クラウドLLM**: 設定画面から API キーを設定（Gemini 等）
4. 詳細は同梱の `INSTALL_GUIDE.md` / スマホ連携は `TAILSCALE_SETUP.md` を参照

## 🔄 アップデート方法
次回以降のバージョンが公開されたら、アプリ内の通知（PC: 吹き出しの🌐ボタン / スマホ: バナーリンク）からダウンロードページを開けます。
**配置手順（データ移行チェックリスト付き）は同梱の `docs/guides/UPDATE_GUIDE.md` を参照してください。**

## 📋 動作要件
- Windows 10/11 (64bit)
- ローカルLLM利用時: 約1GB の追加ディスク領域
- スマホ連携: 同一LAN または Tailscale ネットワーク
