## 1. 実施タスクおよび対応内容

### タスク1: `tests/test_task_lists.py` tearDown の Windows flake 恒久対策 (手帳 ID 83)
- **背景・事象**:
  Windows環境（特に OneDrive 同期フォルダ配下）において、テスト実行終了後の DB ファイル削除時に `PermissionError: [WinError 32]`（プロセスのファイルハンドル保持および同期ロック）が一過性で発生する問題。
- **対策内容**:
  1. `TestTaskLists` に `_remove_db()` クリーンアップヘルパーを実装。`gc.collect()` を呼んで未参照の SQLite コネクションオブジェクトのファイルハンドルを確実に開放。
  2. WAL モードで自動生成されるサイドカーファイル (`-wal`, `-shm`) も削除対象に含め、`PermissionError` / `OSError` 発生時に `time.sleep(0.05)` で最大5回のリトライ処理を実施。
  3. テスト用 DB の配置先をリポジトリ直下から `%TEMP%` (`tempfile.gettempdir()`) 配下へ変更し、OneDrive 同期領域のロック影響を物理的に遮断。
