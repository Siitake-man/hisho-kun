## 手帳 ID 92: app_paths.migrate_legacy_data の Deep Module 分割リファクタ

### 背景・目的
- `app_paths.migrate_legacy_data` は認知複雑度が 102 に達しており、コードベース内最大級の複合処理となっていた。
- クラウド同期領域から非同期データルートへのデータ安全移行 (ADR-2 / P0-4) において、DB移行、マスタートークン移行、バックアップ退避の処理が単一関数内に密結合していたため、モジュール分割と可読性向上を実施した。

### リファクタリング概要
- `app_paths.py` 内で `migrate_legacy_data` から以下の 3 つのヘルパー関数を抽出:
  1. `_migrate_legacy_db`: 旧DB本体 (`-wal`/`-shm` 付随ファイル含む) の非同期領域への安全移行と不変条件の保持
  2. `_migrate_legacy_token`: マスタートークン (`.sync_token`) の安全移行
  3. `_migrate_legacy_backups`: 旧バックアップディレクトリ (`backups/neo_secretary_backup_*.db*`) の安全退避
- `migrate_legacy_data` 本体の認知複雑度を 24 ➔ 8 に劇的削凍し、抽出したヘルパー関数も含め各関数 8 以下を達成。
