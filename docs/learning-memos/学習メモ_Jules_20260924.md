## 1. 実施タスクおよび対応内容

### 優先順①: ID 35 Whisper 音声認識の完全撤去
- **背景と目的**:
  - 不要な機能の引き算ポリシーに基づき、精度・速度に課題のあった内蔵 Whisper 音声文字起こし機能を完全撤去。
  - スマホ OS 標準の音声入力（キーボードマイク）で同等以上の体験が得られるため、フットプリントを削減。
  - 朝会ブリーフィングの TTS 読み上げ機能（Web Speech API）および自律生活生成エンジン (`LifeDreamer`) は影響なく温存。
- **対応内容**:
  - `whisper_transcriber.py`, `tools/e2e_voice_check.py`, `tests/test_whisper_transcriber.py`, `tests/test_voice_sync.py` を削除。
  - `api_tasks.py` から `action_transcribe_voice` を削除。
  - `local_sync_server.py` の `ACTION_HANDLERS_TASKS` から `transcribe_voice` ディスパッチ登録を削除。
  - `web_pet/index.html` から `#mic-btn` および関連コメントを削除。
  - `web_pet/pet.js` から `VOICE_INPUT_ENABLED` 定数、`startVoiceInput`, `stopVoiceRecording`, `_sendVoiceToWhisper` 関連処理を削除。

### 優先順②: ID 57 test_calendar_ui_smoke の skip 判定決定論化
- **背景と目的**:
  - `tests/test_calendar_ui_smoke.py` の `setUp()` 内で `tk.Tk()` 実行時に `self.skipTest()` を呼んでいたため、テスト環境やタイミングによって skip 件数が動的に変動し、決定論性を損なっていた。
- **対応内容**:
  - モジュールロード時に `_check_tk_available()` で一度だけ Tk 可用性を判定。
  - `TestCalendarWindowRendering` テストクラス全体に `@unittest.skipUnless(_TK_AVAILABLE, ...)` デコレータを適用。
  - Tk 不可環境（ヘッドレス Linux 等）ではクラス全体（5テスト）が決定論的にスキップされ、xvfb 環境では全 5 テストが確実に実行・合格するように改修。

---

### 優先順③: ID 43 sync_ai_dotfiles の Vault エクスポート修正
- **背景と目的**:
  - AI Dotfiles バックアップツール (`tools/sync_ai_dotfiles.py`) において、知識の宝庫 (`user_insights`) のエクスポート時に存在しないカラム (`insight_key`) が指定され WARNING が発生し、バックアップから欠落する問題があった。
- **対応内容**:
  - `tools/sync_ai_dotfiles.py` を整備し、`user_insights` テーブルの正規カラム (`id`, `category`, `content`, `context_tags`, `importance`, `created_at`, `updated_at`) に適合したエクスポート関数 `export_knowledge_vault()` を実装。
  - 同期関数 `sync_dotfiles()` にて `~/.ai_dotfiles/knowledge_vault.json` へ正常エクスポート。
  - 全関数に型ヒント、日本語 Docstring、適切な `logging`、例外ログ (`logger.error(..., exc_info=True)`) を整備（例外の握りつぶし禁止規約に準拠）。
  - `tests/test_sync_ai_dotfiles.py` を新設し、最新知見がスキーマエラーなくエクスポートされることを自動テストで検証。
