# ネオ秘書くん インストールガイド (v1.0.0 / Windows 64bit)

社内配布用パッケージ `NeoHisho_v1.0.0_win64.zip` のセットアップ手順です。

---

## 1. 前提条件

| 項目 | 要件 |
|---|---|
| OS | Windows 10 / 11 (64bit) |
| ディスク空き | 2GB 以上 (アプリ本体 約500MB + オフラインAIモデル 約800MB※任意) |
| インストール先 | **Cドライブ直下などを推奨** (例: `C:\NeoHisho`) |
| Python | 不要 (すべて同梱済み) |

> ⚠️ **OneDrive / Dropbox 等の同期フォルダには置かないでください。**
> DBや設定ファイルの書き込みが同期と競合し、破損・二重起動検知の誤動作の原因になります。

---

## 2. インストール手順

1. `NeoHisho_v1.0.0_win64.zip` を任意の場所で解凍する
2. 解凍してできた `NeoHisho` フォルダを `C:\NeoHisho` など **書き込み可能なローカルパス** へ移動する
3. フォルダ内の **`NeoHisho.exe` をダブルクリック** して起動

> 💡 **「WindowsによってPCが保護されました」(SmartScreen) が出た場合**
> 社内配布のため署名がありません。「詳細情報」→「実行」で起動できます。

初回起動時に以下が **自動で作成** されます（手順は不要です）:

- `NeoHisho.exe` と同じ場所に `.env`（設定ファイル。`.env.example` から自動生成）
- 同じ場所に `neo_secretary.db`（データベース）

つまり **フォルダごとコピーすれば設定・データごと引っ越し可能**、フォルダを削除すればアンインストール完了です（レジストリは使いません）。

---

## 3. AI モデルの設定 (どちらか一方でOK)

### A. クラウドAI (推奨 — 品質重視)
1. 起動 → ネオ秘書くんを右クリック → 「設定」→「AIモデル」タブ
2. プロバイダを選択し、APIキーを入力して保存
   - `opencode` / `google` / `openai` / `groq` / `openrouter` / `ollama` / `lmstudio`
3. APIキーは `NeoHisho` フォルダ内の `.env` に保存されます（**他人と共有しないでください**）

### B. オフラインAI (完全無料・ネットワーク不要)
初回のみモデルをダウンロードします（約800MB、数分）:

```powershell
# NeoHisho フォルダで PowerShell を開いて実行 (推奨モデル 350m)
.\NeoHisho.exe --setup-model

# 大きめの高品質モデルを使う場合
.\NeoHisho.exe --setup-model 1.2b
```

完了ダイアログが出たらネオ秘書くんを再起動し、設定でプロバイダ `local_gguf` を選択。

---

## 4. スマホ連携 (Desk Pet)

1. PCのネオ秘書くんを右クリック → 「スマホ連携」→ QRコードを表示
2. スマホのカメラでQRを読み取り、ブラウザで開く（Wi-FiはPCと同じネットワーク）
3. 初回はペアリング承認をPC側で行う

詳細（VPN経由での社外接続）は同梱の `docs/guides/TAILSCALE_SETUP.md` を参照。

---

## 5. Claude Desktop / Cursor などからの MCP 連携

1. ネオ秘書くんを右クリック → 「設定」→「MCP連携」
2. 「自動インストール」ボタン、または各ツール向けのコピーボタンを使用
3. exe版では登録先コマンドが自動的に `NeoHisho.exe --mcp-serve`（MCPサーバーモード）になります

> Claude Code の場合: `claude mcp add neo_hisho_bridge "<exeのフルパス>" --mcp-serve` 相当のコマンドをボタンが生成します。

---

## 6. トラブルシューティング

| 症状 | 対処 |
|---|---|
| ダブルクリックしても何も起きない | ①タスクトレイ/タスクマネージャーに `NeoHisho.exe` がないか確認 ②**二重起動は自動ブロック**されます（すでに起動済みならそのウィンドウを使う） ③既定ポート8765（`NEO_HISHO_PORT` で変更可）を他アプリが占有していないか確認 |
| ウイルス対策ソフトがブロック | 社内配布パッケージです。除外設定に `NeoHisho` フォルダを追加してください（onedir構成は誤検知が起きにくい方式を採用済み） |
| スマホから繋がらない | PCとスマホが同じWi-Fiか確認 → ダメなら QR を作り直す（IPが変わった可能性）→ `TAILSCALE_SETUP.md` のVPN構成へ |
| オフラインAIが遅い | `--setup-model 350m` の軽量モデルを使用してください（1.2b はメモリ8GB以上推奨） |
| 設定を初期化したい | `NeoHisho` フォルダ内の `.env` と各種 `*_config.json` を削除して再起動（会話履歴DBを残すなら `neo_secretary.db` は削除しない） |

---

## 7. アップデート方法

1. 新しい zip を解凍し、**`NeoHisho.exe` と `_internal` フォルダを上書き**
2. `.env` / `neo_secretary.db` / `*_config.json` / `models/` / `backups/` は **そのまま残す**（設定とデータが引き継がれます）

---

## 8. データの保存場所（サポート用メモ）

すべて `NeoHisho.exe` と同じフォルダ直下に集約されています:

```
NeoHisho/
├── NeoHisho.exe            # 本体 (GUI / MCPサーバー / モデルDLツールの3役)
├── _internal/              # 実行ライブラリ・同梱リソース (触らない)
├── .env                    # APIキー等の設定 (初回自動生成)
├── neo_secretary.db        # 会話・タスク履歴DB
├── mcp_config.json ほか    # 各機能の設定 (自動生成)
├── models/                 # オフラインAIモデル (--setup-model で配置)
└── backups/                # 自動バックアップ
```
