- **対象**: NeoHisho v1.0.0 以降を利用しているすべてのユーザー

## 1. アップデート通知の見方

| 端末 | 通知の形 | アクション |
|---|---|---|
| 💻 PC | デスクトップペットの吹き出しに「🔔 アップデートのお知らせ」＋ **🌐 リンクをブラウザで開く** ボタン | ボタンを押すとダウンロードページ（GitHub Releases）がブラウザで開く |
| 📱 スマホ | PWA上部のオレンジ色バナー「⬆ v○.○.○ が利用可能です」 | バナー内のリンクをタップするとダウンロードページが開く |

※チェックは **6時間ごと** に自動で行われます。すぐ確認したい場合はPC側アプリを再起動してください。

## 2. ダウンロード（Git 操作は不要です）

1. 通知のリンク、または下記ページをブラウザで開きます:
   `https://github.com/Siitake-man/hisho-kun/releases`
2. 一番上のリリース（Latest）の **Assets** を展開し、
   `NeoHisho_v○.○.○_win64.zip` をクリックしてダウンロードします。
3. `git clone` や `git pull` などの Git 操作は**不要**です。ソースコードではなく、
   完成済みアプリ一式の zip を取得します。

## 3. 配置手順（ここが最重要です）

### 3.1. まずアプリを終了する
- PCタスクトレイ／ペットウィンドウを閉じ、`NeoHisho.exe` を完全に終了させます。
- **起動したまま上書きすると「ファイルがロックされている」とエラーになります。**

### 3.2. zip を解凍する
- `NeoHisho_v○.○.○_win64.zip` を右クリック → **すべて展開** します。
- `NeoHisho` というフォルダ（中に `NeoHisho.exe` と `_internal` がある）が出てきます。

### 3.3. データ（設定・タスク）を「古いフォルダ → 新しいフォルダ」へコピーする
アプリは**ポータブル設計**（データはすべて exe と同じフォルダに保存）です。
アップデートは「新しいフォルダへ丸ごと載せ替え」＋「データだけコピーし戻し」が安全です。

**コピーすべきデータ（旧フォルダ直下にあります）:**

| ファイル/フォルダ | 内容 | 必須 |
|---|---|---|
| `neo_secretary.db` | タスク・予定・習慣などの本体データ | ✅ 必須 |
| `.env` | APIキー・プロバイダ設定 | ✅ 必須 |
| `models/` | ダウンロード済みローカルLLM（数百MB〜。再DLを避けたい場合） | 推奨 |
| `backups/` | データベースの自動バックアップ | 推奨 |
| `suggest_config.json` | ニュースキーワード等のサジェスト設定 | あれば |
| `webhook_config.json` | 外部カレンダー連携設定 | 使っている場合 |
| `.sync_token` | PC⇔スマホのペアリング情報 | スマホ連携を使っている場合 |

**手順:**
1. 旧フォルダ（今まで使っていた `NeoHisho`）から上記のファイル/フォルダを新しいフォルダへコピーする
   （新しいフォルダの `NeoHisho.exe` と同じ場所＝直下に置く）
2. 動作確認が取れるまで、**旧フォルダは名前を `NeoHisho_old` などに変えて残しておく**（消さない）

### 3.4. 起動して確認する
1. 新しいフォルダの `NeoHisho.exe` をダブルクリック
2. タスク・予定が前のままであること（`neo_secretary.db` のコピー成功の証拠）を確認
3. 問題なければ、数日後に旧フォルダを削除して完了

## 4. よくある配置ミスと対処法

| 症状 | 原因 | 対処法 |
|---|---|---|
| `NeoHisho.exe` をダブルクリックしても一瞬で消える | zip を**解凍せずそのまま実行**している / `_internal` フォルダが無い | zip を必ず展開し、`NeoHisho.exe` と `_internal` が並んだ状態で実行する |
| 「ファイルが使用中」で上書き/削除できない | アプリが起動している | アプリを終了してから操作する（タスクマネージャーで NeoHisho.exe を確認） |
| 起動したらタスク・設定が全部空 | `neo_secretary.db` / `.env` をコピーし忘れた | 旧フォルダから §3.3 のファイルをコピーし直す（旧フォルダを消していなければ復旧できます） |
| ローカルLLMが使えない（応答がない） | `models/` をコピーし忘れた | 旧フォルダの `models/` をコピーするか、`NeoHisho.exe --setup-model 350m` で再ダウンロード |
| スマホと同期できない | `.sync_token` をコピーし忘れた | 旧フォルダから `.sync_token` をコピーするか、スマホ側で再ペアリング |

## 5. FAQ

**Q. Git をインストールする必要はありますか？**
A. いいえ、必要ありません。GitHub Releases ページはブラウザだけで操作できます。

**Q. 毎回データのコピーは必要ですか？**
A. はい。アプリはポータブル設計のため、バージョン載せ替え時にデータのコピー（§3.3）が必要です。
将来のバージョンで自動更新（Level 2）を検討しています。

**Q. 更新通知を一時的に消したい**
A. スマホのバナーは「閉じる」でそのセッション中は非表示になります。PC側は次の新バージョンが出るまで再通知しません。

**Q. うまくいかないときは？**
A. `backups/` にデータベースの自動バックアップがあります。旧フォルダごと戻せば旧バージョンにロールバックできます。
