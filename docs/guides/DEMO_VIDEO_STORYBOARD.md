# 🎬 ネオ秘書くん 30秒デモ動画 絵コンテ ＆ 撮影ガイド

- **動画の目的**: 「席を外してもAIコーディングが止まらない（遠隔承認リモコン）」の価値を、開始3秒で直感的に理解させ、GitHub Star / Qiita LGTM へ誘導する。
- **ターゲット**: Claude Code / Cline / Cursor などのAIエージェントを使って開発しているエンジニア。
- **総尺**: 30秒（X / Twitter / Qiita / YouTube Shorts に最適な尺）

---

## 📱 撮影環境の準備（所要時間：2分）

1. **配置**:
   - PCディスプレイの手前または横に、**古いスマートフォン**をスマホスタンド等で立てて置く。
   - スマホの画面には PWA（`http://<PCのローカルIP>:8765/pet`）を開き、ペット（秘書くん または カイル君）が表示されている状態にする。
2. **PC側の画面**:
   - ターミナル（VS Code / Windows Terminal）で Claude Code または Cline が動いている画面を映す。
3. **撮影機材**:
   - 手持ちのメインスマートフォン（カメラ）で、**「PC画面」と「手前の卓上スマホ」が両方画角に入るアングル（斜め上45度）** から撮影。

---

### カット1: 【課題の提示】AIが止まる（0秒 〜 5秒）
- **カメラ画角**: PC画面のクローズアップ ➔ 引いてスマホも映す。
- **画面の動き**:
  - PC上のAI（Claude Codeなど）がコマンドを実行しようとして `Allow this command? (y/n)` でピタッと停止する。
  - テロップ: **「AIエージェント開発、承認待ちで席を外せない問題……」**
- **アクション**:
  - 開発者（ボス）がマグカップを片手に「ちょっとコーヒー淹れてこよう」と椅子から立ち上がる（背中や手元の動き）。

---

### カット2: 【卓上コックピットの覚醒】スマホに着信！（5秒 〜 15秒）
- **カメラ画角**: 机の上に置かれた「古いスマホ」へフォーカス。
- **画面の動き**:
  - ピピッ！という軽快なチャイム音とともに、スマホ画面のペットが `alarm_ask`（キリッとした表情）に切り替わる。
  - 画面上部に **🚨 深紅の警告パルスバナー** が出現！
  - バナー内容: `⌨️ pytest tests/`（またはコマンド名）
  - テロップ: **「古いスマホが、卓上承認リモコンに転生！」**

---

### カット3: 【神の一手】ワンタップで承認！（15秒 〜 22秒）
- **カメラ画角**: スマホ画面と、そこへ伸びる人間の指。
- **アクション**:
  - コーヒーを持った手、または戻ってきた人間の指が、スマホ画面の大きな緑ボタン **「✅ 承認する」** をポンとタップ！
  - （※イヤホンの再生ボタンを押すジェスチャーでも激アツ！）
  - タップした瞬間、心地よい「ピロリン♪」の決定音が鳴り、スマホトーストに「✅ 承認を送信しました」と表示。
  - テロップ: **「画面を見張る必要なし。ノールックで即承認。」**

---

### カット4: 【解決 ＆ 爆速疾走】AIが再開・ペット大歓喜！（22秒 〜 30秒）
- **カメラ画角**: 手前のスマホと奥のPC画面が両方見えるワイドアングル。
- **画面の動き**:
  - スマホでタップされた瞬間、奥のPCターミナルで止まっていたAIが即座に猛烈な勢いでコードを書き始める！
  - 同時に、手前のスマホのペットとPC上のペットが両手を上げてピョンピョン跳ねる（`celebrate` 歓喜アニメーション）！
  - テロップ: **「席を外しても、開発が止まらない。」**
  - ラストカード（ロゴ ＆ URL）:
    - **ネオ秘書くん (Neo-Secretary)**
    - OSS on GitHub (MIT) / 完全ローカル完結

## 💡 撮影のコツ（5分で撮り切るためのテクニック）

1. **実エージェントがなくても演出可能**:
   - `python tools/test_buzz.py` またはワンライナーで `/api/agent/ask` にテスト用承認リクエストを1本POSTするだけで、スマホ側に全く同じ赤バナーを意図的に発火させられます。
   - 発火用ワンライナー（PowerShell）:
     ```powershell
     .\venv\Scripts\python.exe -c "import urllib.request, json; urllib.request.urlopen(urllib.request.Request('http://localhost:8765/api/agent/ask', data=json.dumps({'agent_name':'Claude Code','command':'git commit -m \"feat: new feature\"','summary':'コミットの承認','risk_level':'strict'}).encode(), headers={'Content-Type':'application/json'}))"
     ```
2. **BGM / 効果音**:
   - BGM: 明るくテンポの良いチップチューン（8bit風の軽快な音楽）。
   - 音声効果音: スマホから鳴るデフォルトのチャイム音がそのまま良い味を出します。
3. **GIF変換**:
   - 撮影した動画から、カット2〜カット4（10秒〜25秒）の部分を切り出して GIF（または WebP アニメーション）に変換し、Qiita記事の冒頭および README に貼り付けると訴求力が10倍に跳ね上がります！
