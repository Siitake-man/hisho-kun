## 🏛️ プロダクト三層構造の基本方針（2026-09-13 確定）

| レイヤー | 役割 | 対象機能 | 開発方針 |
|:---|:---|:---|:---|
| **コア (A)** | **主役・独自の痛点解決** | **AIエージェント遠隔承認** (Claude Code / Cline / Cursor 等)、ゼロトラスト通信、Approval Adapter | 🚀 **最優先投資**。90日後に使われていたい本命。失敗モード堅牢化・実機QA自動化 |
| **世界観 (B)** | **愛着装置・ブランド** | ドット絵ペット、呼吸アニメ、自作キャラMod基盤、秘密の部屋、イースターエッグ | 🔨 **Mod基盤のみ最小実装**。キャラ量産はコミュニティ開放。既存ミニゲーム・演出は現状凍結 |
| **居場所 (C)** | **常駐の理由・背景** | 手帳、TODO、習慣ヒートマップ、iCal読み込み、ポモドーロ、天気 | 🧊 **現状維持**。承認リモコンを常駐させる居場所として完成済み。TickTick等と戦わない |
