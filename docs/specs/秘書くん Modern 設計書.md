## 1. プロジェクト概要

「秘書くん Modern」は、2000年前後に人気を博した日本のフリーソフト「秘書くん2」を現代のWebアプリケーションとして再現したプロジェクトです。オリジナルのレトロなフォルダ風UIデザインを継承しつつ、クラウド対応やモバイル対応など現代的な機能を追加しています。

### 1.1 オリジナル「秘書くん2」について

秘書くん2は、Qu-bit氏が開発したWindows向けスケジューラーソフトウェアです。主な特徴として、カレンダー表示（月表示・バー型・壁紙埋め込み）、9種類の繰り返し予定パターン、伝言メモ機能、付箋機能、アラーム通知機能、スキン変更機能などがありました。

### 1.2 現代版の設計方針

現代版では以下の方針で設計しています。

1. **レトロデザインの継承**: オリジナルのフォルダ風UI、温かみのあるブラウン系配色、罫線ノート風の背景を再現
2. **Webアプリケーション化**: どのデバイスからもアクセス可能なSPA（Single Page Application）として実装
3. **クラウドファースト**: データはサーバーサイドのデータベースに保存し、複数デバイス間で同期可能
4. **拡張性**: Googleカレンダー連携やMCPサーバー機能など、外部サービスとの連携を視野に入れた設計

## 3. ディレクトリ構造

```
hisyokun-modern/
├── client/                    # フロントエンドコード
│   ├── public/               # 静的ファイル
│   ├── src/
│   │   ├── _core/           # 認証・コアフック
│   │   ├── components/      # 再利用可能なコンポーネント
│   │   │   └── ui/         # shadcn/uiコンポーネント
│   │   ├── contexts/        # Reactコンテキスト
│   │   ├── hooks/           # カスタムフック
│   │   ├── lib/             # ユーティリティ
│   │   ├── pages/           # ページコンポーネント
│   │   │   ├── Home.tsx    # ホーム（今日の予定ウィジェット）
│   │   │   ├── Calendar.tsx # カレンダーページ
│   │   │   └── StickyNotes.tsx # 付箋ページ
│   │   ├── App.tsx          # ルーティング定義
│   │   ├── index.css        # グローバルスタイル・テーマ
│   │   └── main.tsx         # エントリーポイント
│   └── index.html
├── server/                    # バックエンドコード
│   ├── _core/               # コアインフラ（認証・OAuth等）
│   ├── db.ts                # データベースクエリヘルパー
│   ├── routers.ts           # tRPCルーター定義
│   ├── storage.ts           # S3ストレージヘルパー
│   └── *.test.ts            # ユニットテスト
├── drizzle/                   # データベーススキーマ
│   ├── schema.ts            # テーブル定義
│   └── migrations/          # マイグレーションファイル

│   └── types.ts             # 共通型定義

```
