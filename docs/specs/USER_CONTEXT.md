# 開発者(User)バックグラウンド情報

## 1. プロフィールとミッション
- **属性:** IT企業マネージャー(課長職)。社内AIラボのPMコース選抜メンバー。
- **専門性 (Triple Skills):**
  - **NW:** エンジニア歴10年（設計・構築）。データセンター等の物理層から論理層まで把握。
  - **PM:** 経験2年以上。金融系PJ等の上流工程・折衝に強み。「死に物狂い」の完遂経験あり。
  - **AI:** n8n等の活用経験あり。現在は「開発もわかるPM/コンサル」への進化を目指す。
- **人生の目的:** 「生命の最適利用」。限られた人生のリソースを余すことなく社会還元し、家族に誇れる自分であること。

## 2. 開発における重要制約 (Constraints)
- **時間的リソースの枯渇:**
  - 家族の闘病サポート(ケア)のため、可処分時間は極めて流動的かつ限定的（平日1-2時間程度）。
  - **要請:** 「隙間時間」で完結できるよう、タスクは可能な限り小さく分解して提案すること。長時間のデバッグが必要な複雑すぎる実装は避けること。
- **思考の重視 (Brain Muscle):**
  - 安易なコピペ用コードよりも、「なぜそう動くのか」の論理構造の理解を優先する。
  - ユーザーが「思考停止」に陥りそうな時は、あえて問いかけを行い、推論と逆算を促すこと。

## 3. プロジェクト「Neo-Secretary」の目的
- **学習目的 (Educational):**
  - LangGraphを用いた「自律型エージェント」の開発を通じて、AI駆動開発のアーキテクチャを深く理解する。
  - 将来的な「愛知移住」や「年収1200万」を見据え、どこでも通用するポータブルスキル（NW x PM x AI）の実証実験とする。
- **機能目的 (Functional):**
  - ユーザーの「生命の最適利用」を支援するため、雑務を極限まで自動化する「真の秘書」を作る。
  - 既存のToDoアプリ(TickTick等)の代替を超え、コンテキストを理解して先回りするエージェントを目指す。

## 4. 技術スタックと嗜好
- **Language:** Python 3.10+
- **Agent Framework:** **LangGraph** (ステートマシンの理解を重視)
- **GUI:** Tkinter (レトロで質実剛健なUIを好む)
- **Philosophy:**
  - 「絶対積極」。バグや壁に当たっても、それを成長の糧と捉える前向きな開発スタイル。
  - 「車輪の再発明」を厭わない。ブラックボックスを嫌う。
