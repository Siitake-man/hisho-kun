① 金庫の鍵を、クラウドの引き出しから引っ越す（P0-4 / ADR-2）

② 「内線だから社員」をやめる（ID 53: Serve 中継と実IP）

Tailscale Serve は来客の電話を内線（127.0.0.1）に繋ぎ替えます。内線番号だけで社員と判断すると、社外の全員が社員証を得ます。

③ 端末の名札は IP ではなく「自分で作った推測不能なID」（ID 50）

ブラウザから MAC アドレスは取得できません。そこで 端末自身が UUID を作って名札にする（推測不能・122bit）。

台帳の行端末名IP（変わる）端末ID（変わらない）
ポイント: フォールバック（IP+名前 → 名前+UA）は device_uuid IS NULL の行に限定。つまりUUIDを送らない攻撃者でも、名札付きの行は乗っ取れません（認証の根拠はあくまで人間承認＋個別トークン）。
