📚 本日の専門用語・完全解体辞典

概念 System One（速い思考）と System Two（遅い思考）

認知科学用語。直感や反射で瞬時に下すミリ秒の判断を「System One」、論理的に深く長考してコードを書く推論を「System Two」と呼ぶ。Jevは典型的なSystem Oneモデルであり、コードを書かせるのではなく「判断だけ」に専念させるのが正しい使い方。

検索工学 2段階選抜（リランキング / Reranking）

膨大なデータ（100個以上のスキル）から、まず軽量モデル（Jev）が高速に確率上位5〜10件をピックアップ（第1段階）。その後、文脈を熟知した上位モデル（Antigravity）が精密に最終決定する（第2段階）手法。コンテキストトークンを劇的に節約できる。

セキュリティ Fail-Closed（安全側遮断）

システムで予期せぬエラーや未初期化状態（コールバックがNone等）が発生した際、絶対に通信を許可せず「遮断（403拒否）」するゼロトラストの鉄則。今回、外部端末の承認バイパス脆弱性を完全封鎖した。
