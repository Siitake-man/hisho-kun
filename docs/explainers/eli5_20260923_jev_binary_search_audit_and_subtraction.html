🔍 二分探索（バイナリサーチ）とは？▼
辞書で言葉を引くときのように、真ん中を開いて「大きすぎるか小さすぎるか」で探索範囲を半分ずつ絞り込んでいくアルゴリズムです。
文字数を1文字ずつ増減させると何百回も試行が必要ですが、二分探索ならわずか8〜12ステップ（約0.05秒）で目標の 27,000 <= tokens <= 29,500 に100%確実に収束させることができます。
⚖️ トークン密度（Token Density）とは？▼
「1文字あたり何トークンになるか」の比率です。英語のアルファベットは1単語（4〜5文字）で約1トークンですが、日本語の漢字や記号、コードのインデントなどは1文字で2〜3トークンを消費することがあります。そのため、「文字数」だけで長さを制限しようとすると、中身によってトークン数が数倍に跳ね上がり、API上限を突き破る原因になります。
🏛️ 蒸留蔵思想（Distillation Vault）とは？▼
AIの気まぐれな思いつきや推測を直接「知識の宝庫」に書き込ませず、必ず「ボス自身の明確な発言」「発生した物理的事実（Gotcha）」「実際に通ったテスト」という確定エビデンスを通過したものだけを長期記憶に封入する設計思想です。AIの幻覚（ハルシネーション）による記憶汚染を防ぎます。
🛡️ フェイルクローズ（Fail-Closed）とは？▼
NWのファイアウォールと同じ思想です。何らかの例外や未定義の状態、判定不能な事象が発生した際に、「とりあえず通す（Fail-Open）」のではなく、「安全のために直ちに遮断・停止する」という防御原則です。P0-4データ境界やJev Tool Guardでも徹底されています。
