🥷 ステルスモード (Stealth Mode)

デスクトップ画面を広く使いたい時や集中作業時に、PCペットを一時的に非表示（タスクトレイ格納）にする機能。スマホ連携中だけでなく、スマホ未接続時でもワンクリックで隠すことができ、エージェントからの問い合わせが来ても勝手に画面に復帰しないよう防護されています。

✂️ 引き算の美学 (Subtractive Design)

「機能を足すこと」ではなく「不要なもの、使われていないものを削ぎ落とすこと」で製品の価値を研ぎ澄ます設計思想。今回、誰も使っていなかった約800行のイースターエッグや、無機質な親愛度数値を完全に削除し、動作の軽快さと保守性を劇的に高めました。

🎭 3スキン体制 (Three-Skin Coexistence)

「秘書くん（クラシック）」「カイル風精霊（クラシック）」「秘書くん (HD-2D・アップデート版)」の3体から好きな相棒を選べる体制。既存の愛着あるアセットを壊さず、新機能も楽しめる後方互換アーキテクチャです。

🎨 プロシージャル・ドット絵 (Procedural Pixel Art)

外部の画像ファイル（PNG）に頼らず、プログラムコード上でピクセルマトリクスとパレットを定義し、HTML5 Canvas等へ動的に描画する技術。ファイル読み込みエラーや404リスクをゼロにし、ネクタイや小物の形状をコードで精密制御できます。
