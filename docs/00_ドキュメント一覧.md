## 3. プロジェクト専用スキル（.agents/skills/）

- `session-start`: 開発開始時のコンテキスト復元・環境チェック・5分マイクロタスク選定
- `session-wrap-up`: 開発終了時の一括ドキュメント追記・学習メモ/Jules指示書生成
- `graph-engineering`: DAG並列開発・独立検証（Verifier）・成果統合（Synthesize）
- `holistic-code-review`: MCPグラフ分析と2軸（Standards/Spec）総合コードレビュー

- `session-wrap-up`: 開発終了時のドキュメント更新・学習メモ生成・Jules/Codex引き継ぎ指示書作成
- `graph-engineering`: Python / CustomTkinter / LangGraph / LLM Factory に特化したDAG並列開発・検証
- `holistic-code-review`: 規約・Spec・モジュール構成に適合したコード全体レビュー
