## 3. 用語境界規約：MentisDB ≠ 知識の宝庫（恒久化）

### 3.1 発生した事象

### 3.2 原因の解剖（証拠ベース）
1. **歴史的経緯**: アプリ内の知見蓄積機能（`user_insights` テーブル）は当初「MentisDB型」と呼称され、
   **2026-09-14 に「知識の宝庫」へ全面改名**（残存0件を謳った）。

   - `.agents/skills/`（deep-audit・graph-engineering・holistic-code-review）: 「ADR / MentisDB への知見永続化」
   - `docs/learning-memos/学習メモ_20260916.md`: 「知見の宝庫（MentisDB）への自律永続化」
   - `docs/developer-ecosystem-*.html`（4箇所）: 「neo_hisho_bridge (MentisDB)」
   - → **「知識の宝庫のツール（remember_boss_insight）」と「MentisDB」が隣接**しており、同一視を誘導。
3. **MCP側の要因**: MentisDB MCP は「エージェント起動時にまず呼べ」と要求するため、誤ってセッション初期化と結合しやすい。

## 5. P0-1 修正の詳細（脆弱性 → 設計 → 検証）

### 5.1 脆弱性（修正前の実測）
```
GET /assets/\Windows\win.ini   →  HTTP/1.0 200 OK  ＋  "; for 16-bit app support"（実ファイル本文）
```
- 旧検査: `if ".." in filename or filename.startswith("/") or ":" in filename:` → **Windows の `\` 始まり絶対パスを通過**
- `Path(ASSETS_DIR) / r"\Windows\win.ini"` → `C:\Windows\win.ini`（Python はルート付きパスでベースを置換）
- 当該分岐は `_check_auth()` の外にあり、サーバーは `0.0.0.0` で待受 → **同一LAN/Tailscaleから任意ASCIIファイルを読み出し可能**

### 5.2 修正設計（Deep Module / Seam）
新規 **`web_assets.py`** に判断を集約し、HTTPハンドラは結果を使うだけにした。
```
resolve_asset_path(filename, assets_root) -> Optional[Path]
  ① 危険表現の事前排除: "[\\:%]|^/" （\・:・%・先頭/）
  ② 拡張子アローリスト: .png .jpg .jpeg .gif .webp .svg .ico
  ③ 解決後のルート配下検証: Path.resolve() + is_relative_to(root)
  ④ 実在確認（is_file）
  → すべて満たす場合のみ Path を返し、それ以外は None（呼び出し側は404）
```
- **認証は付与しない**（ブラウザは manifest/icons を Bearer なしで取得するため）。したがってパス検証が唯一の防壁であり、テストで凍結する。
- `Content-Type` は `guess_asset_content_type()`（`mimetypes`）で実ファイルから導出（旧実装は常に image/png）。

### 5.3 検証結果（修正後の実サーバーPoC・生ソケット）
| 要求 | 結果 |

## 10. 学び（技術・比喩・Gotcha）

### 10.1 習得した技術
1. **パス検証の多層防御**（危険表現排除 → 拡張子アローリスト → `resolve()`+`is_relative_to()`）。
2. **公開アセットに認証を足せない設計判断**（ブラウザは Bearer なしで manifest/icons を取得）→ パス検証が唯一の防壁。
3. **テストのハーメティシティ**: import時束縛・環境変数を扱う検証は `reload` ではなく**サブプロセス隔離**。
4. **`os.environ` に依存しない `.env` 直読み**（`load_dotenv` の発火順に依存しない）。
5. **独立査読の威力**: 自分で書いた全緑テストは「自分の書いた範囲」しか守らない。
6. **アイコンは梱包問題**: ウィンドウ(Tk)・トレイ(pystray)・EXE(PyInstaller)・PWA(Manifest) で仕組みが別 → 共通Seamが必要。
7. **PWAアイコンの実在×サイズ一致原則**（宣言と実体が違うとインストールが拒否される）。

### 10.2 身近な比喩
- **勝手口の柵**: `/assets` は宅配（ブラウザ）用に開けておく勝手口。合鍵を配るのではなく、**家の中へ入れない柵**を二重三重に張る。
- **健康診断の自己申告**: 全緑のテストは“自分で書いた問診票”。別の医師（独立査読）の触診で初めて病気が見つかる。
- **索引カード（DBインデックス）**: 本棚を端から走査する代わりに索引で一直線。使われているかは `EXPLAIN QUERY PLAN` で確認。
- **呼び鈴の間隔（30Hz化）**: 0.01秒ごとにノックし続けるのを0.03秒へ。体感は同じで体力（CPU）消費が減る。

### 10.3 Gotcha
- `Path(base) / r"\Windows\win.ini"` は **base を捨ててドライブ直下**を指す（Windows特有の落とし穴）。
- Tk の `wm iconbitmap` は Windows で設定後も**問い合わせに空文字**を返す（テストは戻り値で担保する）。
- Windows コンソール（cp932）は絵文字で `UnicodeEncodeError`（CLI出力はASCII推奨。`tools/scan_git_secrets.py` も同問題で要修正）。
- PowerShell の `>` リダイレクトは **UTF-16** になる → `cmd /c "... > file 2>&1"` を使う。
- `pytest` の stderr 警告で PowerShell が `NativeCommandError` を出す → リダイレクトで回避。
- 複数行 `old_text` 置換は **CRLF ファイルで失敗**する（単一行アンカーを使う）。
